# Clixx Commerce Application

A production-style multi-service e-commerce application
deployed through the Clixx GitOps Platform.

## Technology Stack

- Python / FastAPI
- React / TypeScript
- PostgreSQL
- Redis / Valkey
- Docker
- Kubernetes
- GitHub Actions
- Trivy
- Argo CD

## Engineering Goals

- Secure CI/CD
- Kubernetes workload management
- Application reliability
- Observability
- Horizontal and node autoscaling
- Production troubleshooting
